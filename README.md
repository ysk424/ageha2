# 揚羽 0.4.0

ブレンダー5.2以降、ウィンドウズ64ビット版向けの、髪を用意するところからシミュレーションまでを一つにまとめた拡張です。表示名と三次元ビューのタブ名は **揚羽** です。

## 方針

- 植毛、縦列植え、前髪カットは `ageha` の作業手順を継承
- シミュレーターはアストラ完成版の髪4・エーシーズに固定
- 旧式の接触射影法、拡張位置基準動力学、計算法の選択画面は収録しない
- `kami4_solver/` の数値計算コードと動的ライブラリは採用タグ `baseline-local-fk-adopted-20260917` から変更しない
- 完全な採用設定は `presets/local-fk-contact-20260917.json`
- **最小計算長は初期値30センチメートル**。30センチメートル以下の毛だけ計算内部で非表示延長し、表示とキャッシュは元の長さへ戻す
- 曲げ剛性5×10⁻⁷、根元2点固定、長さ補正8回、局所順運動学の第2版など、採用済み設定を初期値として復元
- エーシーズの全計算設定を「揚羽」パネルで表示・編集
- ベイク完了時にキャッシュ再生を自動で有効化し、タイムラインへ結果を反映
- 入力変更時は過去のキャッシュを削除せず、次回ベイクを新しいキャッシュへ切り替える

## 使い方

1. 三次元ビューの **揚羽** タブを開く。
2. 入力する髪とボディを指定する。服などは「服・追加コライダー」のコレクションへ入れる。
3. 必要なら「ヘッドマスク作成」から髪を植える。
4. 「セットアップ検証」を実行する。
5. 開始・終了フレーム、固定する根元点数、髪4の計算設定を確認する。
6. 「全フレーム計算」を実行する。完了後はキャッシュ再生が自動で有効になる。

髪4は元の髪を変更せず、`Kami4_BVH_髪_計算結果` を作ります。キャッシュ先を空欄にすると、ブレンドファイルの隣（未保存なら利用者用フォルダー）へ日時付きの新しい `kami4_cache` を作ります。

## 構成

```text
ageha2/
  __init__.py             # 揚羽ワークフローと統合登録
  ui.py                   # 「揚羽」一体型パネル
  _mask_plant.py          # ageha 由来の植毛処理
  _groom_ops.py           # ageha 由来の前髪処理
  kami4_solver/           # 髪4の数値計算実行部
  vendor/kami4-hair-solver/ # 髪4の開発記録とソース
```
