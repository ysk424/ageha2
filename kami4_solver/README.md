# 髪4 髪物理計算機

ウィンドウズ64ビット版、ブレンダー5.2、クーダ計算能力120向けです。ヘアカーブと評価済みのコライダーを入力する、計算回数固定の髪物理計算機です。

三次元ビューの「髪4」で入力する髪と衝突メッシュを指定し、「初期化」「全フレーム計算」の順に実行します。全フレーム計算は主処理のタイマーで1フレームずつ進み、エスケープキーで中止できます。「キャッシュ再生」を有効にすると、フレーム変更時に保存済み結果を読み込みます。「開始形状へ戻す」は計算前の形へ戻します。元の入力は編集せず、結果を `Kami4_髪_計算結果` に作ります。

共通の `parameters.json` が材質と固定計算回数を定義します。初期化後に設定を変更した場合は再初期化してください。キャッシュは接続構造と設定のハッシュ値、フレームごとの巡回冗長検査値を確認します。異なる設定ではキャッシュを再生せず、別のキャッシュフォルダーを使用します。

解析コライダーは追加コレクション内のオブジェクトに `kami4_type`（0：局所Z平面、1：球、2：カプセル、3：無限円柱）、`kami4_radius`、`kami4_half_length`、`kami4_friction` を指定します。変換は評価済みの世界変換を使います。非均一な拡大縮小は適用してください。

衝突メッシュは元の三角形を画像処理装置上の階層境界箱で扱い、両面の離散的な点と表面の接触を計算します。自己衝突、連続衝突判定、毛束の辺と三角形の接触は行いません。移動量上限の超過は診断表示へ記録します。現在の実シーンは200フレーム完走していますが、仕様の全受入条件を満たした認定版ではありません。詳細はリポジトリの `docs/RESULTS_JA.md` を参照してください。
